# Content and Asset Provenance

## Devotionals

The daily reflections, questions, and prayers in `public/content/devotionals.json` are original Work Day with God application content generated for this project. They do not reproduce third-party devotional writing.

Each entry identifies its KJV anchor reference and carries the attribution `Original reflection by Work Day with God`.

## Scripture

The installer uses the normalized historical translation caches selected from the repository’s `data/electron_cache` directory. Only the nine translations listed in the README are enabled. Before public commercial distribution, the project owner should retain a release-specific rights review documenting the provenance and public-domain status applicable in target countries.

## Scenic artwork

The daily scenes under `public/scenes` are original application assets composed from AI-generated scenic sources created for Work Day with God. Prompts require natural scenic imagery without people, text, logos, watermarks, buildings, or explicit religious symbols. Each date receives a deterministic composition with distinct source pairing, crop, seasonal grade, and tonal treatment. The manifest records source filenames and output hashes. Final files are optimized WebP assets intended for offline use.
