# Linux 1.4.4 Testing Preview

Work Day with God 1.4.4 is available for Linux x86_64 as a separate testing preview. The release includes AppImage, DEB, and RPM packages.

The AppImage is intended for portable use. The DEB package is intended for Debian and Ubuntu-based distributions. The RPM package is intended for Fedora, openSUSE, and related distributions. Linux remains a testing release because desktop environments, display servers, notification systems, and package policies vary across distributions.

Download the packages from the [v1.4.4 Linux testing release](https://github.com/mcographics/WorkDaywithGod/releases/tag/v1.4.4-linux-beta.1). The packages are unsigned, so distribution security warnings are expected.
